# Studio media — última etapa

Status: **adiado por decisão de Cassiano em 05/10/2026**

A estrutura, copy, rotas, navegação e estados podem avançar com placeholders neutros. Imagens entram somente depois que o restante estiver estabilizado.

## Regra

- imagem que funciona como **prova de peça/produto/processo** precisa ser foto real;
- não gerar render sintético para fingir trabalho produzido;
- diagrama explicativo pode ser desenhado/gerado depois, desde que seja claramente diagrama;
- asset atmosférico/de apoio pode ser produzido depois quando não alegar prova real;
- placeholder atual deve continuar neutro e identificado.

## Não necessário agora

Não precisamos gerar nesta fase:

- ícones de serviço;
- ilustrações de benefícios;
- objetos 3D fictícios;
- fundos neon;
- render de placa/caixa como se fossem peças produzidas;
- imagens apenas para preencher espaço.

## Gate da última etapa

A fase de mídia começa quando:

1. estrutura e copy estiverem estáveis;
2. CI estiver verde;
3. rotas e responsividade estrutural estiverem funcionando;
4. Cassiano enviar as fotos que quer usar;
5. os assets que realmente precisam ser desenhados forem produzidos somente depois disso.
